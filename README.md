# Blazor Circular Gauge Customization

A comprehensive Blazor sample demonstrating how to customize the [Blazor Circular Gauge](https://www.syncfusion.com/blazor-components/blazor-circular-gauge) component. Learn to work with multiple axes, customize ticks, labels, and ranges to create sophisticated gauge visualizations.

## Overview

The Blazor Circular Gauge is a powerful visualization component for displaying measurements and metrics. This sample demonstrates essential customization techniques including:

- **Multi-axis configuration** - Create multiple axes with different scales and ranges
- **Visual customization** - Customize colors, sizes, and styling of gauge elements
- **Advanced labeling** - Format axis labels and configure label positions
- **Range definition** - Define and style multiple ranges within the gauge
- **Pointer setup** - Configure pointers to display gauge values

## Features

- **Multi-Axis Support** - Create gauges with multiple independent axes, each with custom scales, ranges, and visual styling
- **Advanced Tick Customization** - Configure both major and minor ticks with customizable colors, widths, heights, and intervals
- **Flexible Label Formatting** - Format axis labels with custom units, angles, and positioning for optimal readability
- **Range Definition & Styling** - Define multiple ranges with independent colors, opacity levels, and position control (inside/outside)
- **Visual Styling** - Customize background colors, transparency, line styles, and element sizing for professional-looking gauges
- **Interactive Pointers** - Configure and display multiple pointers with customizable appearance and behavior
- **Modern Framework** - Built on .NET 10 with latest Blazor Server-side rendering capabilities

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/how-to-customize-the-blazor-circular-gauge-component.git
cd how-to-customize-the-blazor-circular-gauge-component
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
